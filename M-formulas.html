🧮 ตย.2 · แปลง Address (Paging)

โปรแกรม 16 B เพจละ 4 B (offset 2 บิต) · Page Table: 0→f5, 1→f6, 2→f1, 3→f2 — หา PA ของ logical 6 และ 2

ขั้น 1page# = logical ÷ ขนาดเพจ (ปัดเศษทิ้ง) · offset = logical mod ขนาดเพจ

⚡ ตย.3 · EAT (TLB)

โจทย์RAM 1 μs · TLB ε = 0.1 μs · hit ratio α = 0.8
ขั้น 1 hitα×(ε + 1) = 0.8×1.1 = 0.88 (หาเจอ → อ่าน RAM 1 ครั้ง)
ขั้น 2 miss(1−α)×(ε + 2) = 0.2×2.1 = 0.42 (ไม่เจอ → อ่าน RAM 2 ครั้ง)
ขั้น 3 รวมEAT = 0.88 + 0.42 = 1.3 μs (ตรงสูตร 2 + ε − α = 2.1 − 0.8 ✓)
กลับด้านε=0.25 ต้องการ EAT = 1.35 → h×1.25 + (1−h)×2.25 = 1.35 → 2.25 − h = 1.35 → h = 0.90

🏦 ตย.6 · Banker's — เช็ก Safety

Available = (3,3,2) · Need = Max − Allocation → P0(7,4,3) P1(1,2,2) P2(6,0,0) P3(0,1,1) P4(4,3,1) — วนหาใคร Need ≤ Work แล้วปล่อยคืนทั้ง Allocation

จบก่อนเงื่อนไขWork ใหม่ (คืนของ)

P3(0,1,1) ≤ (5,3,2) ✓(7,4,3)
P4(4,3,1) ≤ (7,4,3) ✓(7,4,5)
