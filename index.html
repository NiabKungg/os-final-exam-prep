รูปแบบข้อสอบ Final (จากรีวิวรุ่นพี่)

  • ปรนัย 2 ตัวเลือก (ถูก/ผิด) — ระบบคะแนนแบบกินคน: ตอบถูก +2, ตอบผิด −1, ไม่ตอบ 0 ⇒ ไม่แน่ใจจริง ๆ ให้ข้าม อย่าเดามั่ว
  • เติมคำตอบ — ส่วนมากเป็นการเติมตัวเลขหรือคำสั้น ๆ (เช่น คำนวณ physical address, จำนวน page fault, waiting time)
  • ข้อสอบเยอะกว่า Midterm + โจทย์คำนวณเยอะกว่า — 3 ชั่วโมงแทบไม่พอ เน้นความเร็ว
  • ส่วนมากคนคำนวณ Paging กันไม่ทัน — ต้องฝึกคำนวณ address translation ให้ลื่นมือ 🔥
  • Open Book — เอา Handout/ชีทเข้าได้ แต่ไม่มีเวลาไปเปิดหาทีละข้อ ควรจดสรุปสั้น ๆ ติดมือไปด้วย
  • โค้ดทุกข้อ Compile ผ่านหมด — ไม่มีคำตอบว่า "Error" ถ้าเจอโจทย์ไล่โค้ด fork ให้ไล่ลำดับการทำงานจริง ๆ ระวังจุดหลอก
🚨 สิ่งที่ต้องฝึกให้เร็วที่สุด (ตามลำดับความสำคัญ)
  1. Paging address translation — แปลง logical → physical แบบเร็วและแม่น (บทที่ 11)
  2. Page Replacement — นับ page fault FIFO / Optimal / LRU ให้ไว (บทที่ 12)
  3. CPU Scheduling — วาด Gantt หา TAT/WT ทุกอัลกอริทึม (บทที่ 5)
  4. Banker's Algorithm — หา safe sequence (บทที่ 9)
  5. ไล่โค้ด fork/exec/wait — นับ process, เดา output (บทที่ 3)
