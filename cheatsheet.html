2. Process / fork

  • fork(): ใน parent คืน PID ลูก (>0) · ใน child คืน 0 · ติดลบ = error
  • fork ติดกัน n ครั้งไม่มีเงื่อนไข → process = 2ⁿ (ลูกใหม่ 2ⁿ−1) — วาด process tree ถ้ามีเงื่อนไข
  • ลูกในลูป ต้อง exit() — ไม่งั้นวนลูปสร้างลูก/หลานต่อ (output รวน)
  • exec() สำเร็จ → โค้ดหลังบรรทัดนั้นไม่รันเด็ดขาด (fail ค่อยรันต่อ) · execlp(f, arg0, …, NULL): l=list, p=PATH · cd เป็น shell built-in exec ไม่ได้
  • wait(NULL) รอลูกใดก็ได้จบ · waitpid(pid,&s,0) รอเจาะจง · exit status ใช้ได้ 0–255 · พิมพ์ status ต้องผ่าน WIFEXITED/WEXITSTATUS
  • Orphan = พ่อตายก่อน → init/systemd รับเลี้ยง (PPID เปลี่ยน) · Zombie = ลูกตาย พ่อไม่ wait → สถานะ Z/defunct · Cascading termination = พ่อโดน terminate ลูกหลานโดนตาม
  • โค้ดข้อสอบ compile ผ่านหมด ไม่มีตอบ Error · ไม่มี wait ห้ามสรุปลำดับพิมพ์

3. Thread & Sync

  • Thread แชร์ code/data/heap — ส่วนตัวแค่ PC, registers, stack · Model: Many-to-One (early Unix), One-to-One (Win NT+/Linux/Solaris9+), Many-to-Many (Solaris<9, Tru64)
  • Java: priority 1–10 (default 5, มาก=สูง) — ไม่การันตีลำดับ! ห้ามฝาก correctness กับ scheduler
  • Critical section 3 เงื่อนไข: Mutual Exclusion, Progress, Bounded Waiting
  • count++/-- = 3 คำสั่งเครื่อง (read/modify/write) → race condition
  • Peterson: flag[i]=true; turn=j; รอเมื่อ flag[j] && turn==j (turn ให้เพื่อน = bounded waiting)
  • Bakery: จ่ายเลข max+1, เทียบ (number, pid) แบบ lexicographical

4. Semaphore / Monitor / Java

  • wait(S): S≤0 รอ / ไม่งั้น S−− · signal(S): S++ (อุปมาโหลหิน: หยิบ/คืน)
  • Bounded buffer: mutex=1, empty=n, full=0 · Producer: wait(empty)→wait(mutex)→เขียน→signal(mutex)→signal(full) · Consumer: wait(full)→wait(mutex)→อ่าน→signal(mutex)→signal(empty)
  • สลับมาเป็น wait(mutex) ก่อน = deadlock! ทรัพยากรก่อนล็อกเสมอ
  • Readers-Writers: wrt=1, readcount=0 — reader แรก wait(wrt), reader สุดท้าย signal(wrt)
  • Dining Phil: chopstick[5]=1, wait(ซ้าย)+wait(ขวา) → หยิบซ้ายพร้อมกัน = deadlock · Monitor DP (test เพื่อนบ้าน) ไม่ deadlock แต่ starvation ได้
  • Monitor: 1 process ใน monitor · x.wait() หลับ + x.signal() ปลุก1 — ไม่มีใครรอ → สัญญาณหายเปล่า (ไม่มี counter)
  • Java: synchronized = ล็อก object · wait() คืน lock+เข้า wait set · notify() สุ่ม 1 ตัวไป entry set (ไม่รันทันที) · notifyAll() ปลุกหมด · yield() ไม่คืน lock!

5. Deadlock

  • 4 เงื่อนไขครบพร้อมกัน: Mutual Exclusion, Hold & Wait, No Preemption, Circular Wait
  • RAG: ไม่มี cycle = ไม่ deadlock แน่ · cycle + single instance = deadlock แน่ · cycle + multiple = "อาจ"
  • Prevention: ตัด 1 เงื่อนไข (circular wait → เลขทรัพยากร ขอจากน้อยไปมาก) — ทฤษฎีดี ปฏิบัติไม่คุ้ม
  • Avoidance: แจ้ง Max ล่วงหน้า, safe state เท่านั้น · single instance = claim edge + เช็ค cycle · multiple = Banker's
  • Banker's: Need = Max − Allocation · ขอได้เมื่อ Request ≤ Need และ ≤ Available แล้วไล่: หา Need ≤ Work → Work += Allocation → จนหมด = SAFE (unsafe = ไม่ให้ รอ)
  • Detection: single instance → wait-for graph (ตัด resource ออก) หา cycle · OS ส่วนใหญ่ (Unix) เมิน deadlock

6. Memory — Partitions & Segmentation

Relocation/Base: PA = Base + Logical  |  Segmentation: เช็ค d < Limit (ผิด=trap) แล้ว PA = Base + d
  • Fixed partition → Internal frag (เศษในช่องจองแล้ว) · Variable partition / Segmentation → External frag (รวมว่างเยอะแต่ช่องเดียวไม่พอ) · แก้: coalescing / compaction (ต้อง dynamic relocation)
  • First-fit = หลุมแรกที่พอ (เร็ว) · Best-fit = เหลือน้อยสุด (ช้า เศษจิ๋ว) · Worst-fit = หลุมใหญ่สุด (เหลือชิ้นใหญ่ให้งานต่อไป)
  • Static linking ซ้ำ lib ทุกโปรแกรม · Dynamic linking ผ่าน stub แชร์ lib ครั้งเดียว (10MB+20MB vs 22MB ตย.วิดีโอ: 70 → 54 MB)

7. Paging 🔥 (เรื่องที่คนไม่ทัน)

บิต offset = log₂(page size) · บิต page# = บิต address − บิต offset
PA = (Frame × PageSize) + Offset  —  ห้ามบวก frame+offset ตรง ๆ!
  • จำนวนเพจ = ceil(ขนาดโปรแกรม ÷ page size) — 42/4 → 11 เพจ (ปัดขึ้น, IF = 2B)
  • เพจนับเริ่ม Page 0 · Paging: ไม่มี external frag แต่มี internal frag ที่เพจสุดท้าย
  • Valid/invalid bit ดูระดับทั้งเพจ — กัน offset เกินโปรแกรมไม่ได้ · PTBR ชี้ตาราง, PTLR ชี้ความยาว
  • ไม่มี TLB = RAM 2 ครั้ง/การอ่าน · TLB hit = 1 ครั้ง · miss = ค้น TLB + 2
  • EAT = α(1+ε) + (1−α)(2+ε) = 2 + ε − α (ตย. ε=0.1, α=0.8 → 1.3 μs)
  • 32-bit, 4KB page → page# 20 บิต → 2²⁰ × 4B = 4MB/page table/process
  • Two-level 10|10|12: inner tables = ceil(จำนวนเพจ ÷ 1024) · 1MB → 256 เพจ → 4+4 = 8KB · 8MB → 2048 เพจ → 4+8 = 12KB

8. Virtual Memory & Page Replacement 🔥

  • Demand paging: โหลดเมื่อใช้ (lazy swapper/pager) · Page fault 6 ขั้น: trap → เช็ค invalid จริงไหม → หาเพจบนดิสก์ → หา frame ว่าง (ไม่มี→replace) → อัปเดตตาราง+valid → restart
  • เพจ dirty (แก้แล้ว) ต้อง write back ก่อนแทนที่
  • FIFO มองคิว · Optimal มองอนาคต (ใช้จริงไม่ได้) · LRU มองอดีต — นับ fault: จำผล 7,0,1,2,0,3,0,4,2,3,0,3,2,1,2,0,1,7,0,1 (3 frames) = 15 / 9 / 12
  • Belady (FIFO): เพิ่ม frame fault อาจเพิ่ม (1,2,3,4,1,2,5,1,2,3,4,5: 3f=9, 4f=10) — LRU/OPT ไม่มีปัญหานี้
  • EAT = (1−p)·mat + p·service (mat 200ns, service 8ms, p=0.001 → 8.2μs)
  • Thrashing: สลับเพจตลอด CPU ดิ่ง, OS เพิ่ม process = ยิ่งแย่ · Working set: D = ΣWSSᵢ; D > m → suspend process
  • 128×128 row-major: column-นอก = 16,384 faults · row-นอก = 128 faults

9. File System

  • FAT32 ไฟล์สูงสุด 4GB (ตันแน่นอนไม่ว่าดิสก์เหลือเท่าไร) · NTFS/ext4 มี journaling · exFAT ไม่มี · APFS ของ Apple (snapshot/encrypt)
  • Contiguous: เร็วสุด แต่ external frag + ขยายยาก · Linked: random ช้ามาก pointer พังไฟล์ขาด · Indexed: random เร็ว เปลือง index block · FAT = ดึง pointer รวมตารางใน RAM
  • inode 15 pointers (12 direct + 3 indirect): entries/block = block÷pointer (4KB÷4B = 1024) · สูงสุด = 12×4KB + 4MB + 4GB + 4TB ≈ 4TB
  • Hard link: ชี้ inode เดียวกัน, นับ refcount, ตายเมื่อ = 0, ห้ามข้าม partition / ห้ามชี้ dir · Soft link: เก็บ path, ต้นทางลบ → broken, ข้าม partition + dir ได้
  • mount อุปกรณ์ → mount point · umount ก่อนถอด
  • R=4, W=2, X=1 · 761 = rwx / rw- / --x · 6 = rw- (ไม่ใช่ r-x = 5)

10. IPC เร็ว ๆ

  • signal(): ติดตั้ง handler · SIGKILL(9) จับ/เมินไม่ได้ · kill ไม่ใส่ชื่อ = SIGTERM · raise() ส่งให้ตัวเอง, kill(pid,sig) ส่งข้าม process (pid>0 เจาะจง, 0=กลุ่มเดียวกัน, −1=ทุกตัวที่มีสิทธิ์ยกเว้น init)
  • pipe(pfd): pfd[0]=read, pfd[1]=write — ทางเดียว · fork แล้วได้ 4 ปลาย → ปิดข้างที่ไม่ใช้ · สองทาง = สองท่อ
  • dup2(fd, fd2): "fd อยากเป็น fd2" — redirect stdout/stdin ทำ ls|wc ได้
  • SHM: server shmget(IPC_PRIVATE|key, size, IPC_CREAT|0666) → shmat(id,NULL,0) → ใช้ → shmdt → shmctl(id, IPC_RMID) · client ไม่ใส่ IPC_CREAT · server เริ่มก่อน · key: เลขตรง/ftok(path,id)/IPC_PRIVATE
  • Blocking = synchronous, Non-blocking = asynchronous

11. Boot / Mode / เกร็ด

  • Boot: Power → POST → BIOS(→MBR) หรือ UEFI(→ESP, GPT, Secure Boot) → Bootloader → โหลด Kernel → OS init
  • mode bit: 0 = kernel, 1 = user · privileged instructions ใช้ได้เฉพาะ kernel · interrupt มาจากฮาร์ดแวร์, trap มาจากซอฟต์แวร์ (exception/system call)
  • API: Win32 (Windows) / POSIX (Unix/Linux/macOS) / Java (JVM) — printf ใช้ write() ข้างใน
  • Monolithic = เร็วแต่พังพากัน · Microkernel = ปลอดภัย แต่ส่ง message ช้ากว่า
  • Container แชร์ kernel host (เบา เร็ว พกพาง่าย) · VM จำลองทั้งเครื่อง+OS (หนัก ช้า แยกสนิท)
  • Hard real-time: พลาด deadline = พังทลาย, ใช้ time-sharing ไม่ได้ (VxWorks, RTXC) · Soft = มัลติมีเดีย/VR
