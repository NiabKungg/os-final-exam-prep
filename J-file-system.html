J. File System (OSNo10)

📖 รู้จักส่วนนี้ก่อนอ่าน

ความหมาย: File System = ผู้จัดการไฟล์บนดิสก์ — ตั้งชื่อ เก็บ ดึง แก้ไข จัด metadata และกำหนดสิทธิ์การเข้าถึง โดยที่เราไม่ต้องรู้เลยว่าข้อมูลอยู่เซกเตอร์ไหนของฮาร์ดดิสก์

ความสำคัญกับข้อสอบ: เทียบ FAT32 (ระบบไฟล์เก่า ไฟล์เกิน 4GB ไม่ได้)/NTFS (ระบบไฟล์ของ Windows)/ext4/exFAT (FAT32 ตัวใหม่ ไฟล์ใหญ่ได้)/APFS (ระบบไฟล์ของ Apple), วิธีจัดสรรบล็อก 3 แบบ, คำนวณ inode (โครงสร้างเก็บข้อมูลไฟล์ของยูนิกซ์), hard link vs symbolic link, สิทธิ์ rwx → ส่วนใหญ่ออกถูก/ผิด + โจทย์คำนวณสั้น ๆ

ใช้จริงในคอมพิวเตอร์: เลือกฟอร์แมตแฟลช (FAT32 เก็บไฟล์เกิน 4GB ไม่ได้!), คำสั่ง chmod/ls -l ที่เจอทุกวันใน Linux, สร้าง shortcut ไฟล์ = symbolic link — ใช้ในชีวิตประจำวันจริง

J1. File System รับผิดชอบอะไร

จัดการเก็บ/ดึง/จัดระเบียบข้อมูลบน storage — หน้าที่: ตั้งชื่อ+โครงสร้างไฟล์ · เก็บข้อมูล · ดึง/แก้ไข · Metadata · ความปลอดภัย/สิทธิ์เข้าถึง · หัวใจคือ abstraction: interface เข้าถึงไฟล์เหมือนกันไม่ว่าข้อมูลอยู่บน HDD/SSD/USB (device independence — จาก Quizizz 4 ข้อ 2)

J3.1 คำนวณ index / inode 🔥 (สูตรเดียวใช้ทุกโจทย์)

Entries ต่อ 1 index block = Block Size ÷ Pointer Sizeจาก Quizizz 4: บล็อก 2KB ÷ pointer 4B = 512 entries → ไฟล์ใหญ่สุด single-level = 512 × 2KB = 1MB

UNIX Combined Scheme — inode (สไลด์ p.29, block 4KB, pointer 4B): มี pointer 15 ตัว

Pointerจำนวนคำนวณขนาด
Direct ชี้ data ตรง ๆ1212 × 4KB48 KB
Single indirect1(4KB÷4B) × 4KB = 1024 × 4KB4 MB
Double indirect11024² × 4KB4 GB
Triple indirect11024³ × 4KB4 TB
ไฟล์ใหญ่สุด ≈ 48KB + 4MB + 4GB + 4TB≈ 4 TB

J4. Directory (โฟลเดอร์/สารบัญไฟล์) · Tree vs Acyclic Graph

  • Directory = symbol table แปลง "ชื่อไฟล์ → ข้อมูลไฟล์" · operations: search, create, delete, list, rename, traverse
  • Tree: ไฟล์มี parent เดียว — ปลอดภัยแต่แชร์ไม่ได้
  • Acyclic graph (ไม่มีวงวน): แชร์ได้ผ่าน link — ปัญหา: aliasing (ไฟล์เดียวหลายชื่อ), การลบไฟล์แชร์

การลบไฟล์แชร์ 2 แนวทาง

แนวทางทำอย่างไรข้อควรระวัง
ลบเมื่อไรก็ได้ลบไฟล์ทันทีที่ใครสั่งDangling pointer — link ที่เหลือชี้หาอะไรที่ไม่มีแล้ว (แนวทาง symbolic link)
เก็บจน reference หมดนับ reference count: เพิ่ม link → count+1, ลบ link → count−1, count = 0 ค่อยปล่อยพื้นที่ต้องตรวจว่ากราฟไม่มีวงวน (cycle) — แนวทาง hard link ของ UNIX

Hard Link ln original newSymbolic Link (ลิงก์แบบเก็บ path (shortcut)) ln -s original new

J7. Protection — สิทธิ์ RWX 🔥

เจ้าของไฟล์คุมได้ 2 อย่าง: what can be done (read/write/execute) กับ by whom (owner/group/others)

R = 2² = 4 · W = 2¹ = 2 · X = 2⁰ = 13 กลุ่ม: owner, group, other (public) — ตัวอย่างสไลด์ p.50: owner=7 (rwx), group=6 (rw-), public=1 (--x) = 761
